# 🚀 JEN RUSH v2.0 - 2D Neon Arcade Browser Game

**JEN RUSH** is a fast-paced, high-energy 2D neon arcade game built with pure web technologies (**HTML5**, **CSS3**, **Vanilla JavaScript**, and **HTML5 Canvas**).

Created with ❤ by **JEN**.

---

## 🎮 How to Open & Play on Windows

You don't need to install any heavy engines, servers, or libraries! You can run the game directly in any browser on your computer.

### Step-by-Step Instructions:
1. Open File Explorer on Windows and navigate to your game folder: `C:\jen rush`.
2. Locate the file named **`index.html`**.
3. **Double-click `index.html`** (or right-click -> Open With -> Google Chrome / Microsoft Edge / Mozilla Firefox / Brave).
4. Click **🚀 PLAY NOW** to start dodging asteroids and collecting coins!

## 🌟 Upgraded v2.0 Features

1. **Deep-Space Parallax Background**: 3-layer parallax starfield with space dust and glowing nebula gradients.
2. **Smooth Delta-Time Physics**: Smooth acceleration, deceleration, lerp touch-dragging, and strict boundary clamping.
3. **Animated Gold Coins**: Gentle floating sine-wave motion, 3D rotating shimmer line, and gold particle sparkle bursts on pickup.
4. **Professional UI & Glassmorphism**: Futuristic typography, glowing cyan (`#00f3ff`) and magenta (`#ff00ff`) accents, accessible focus rings, and animated score bumps.
5. **Web Audio Synthesizer**: Custom retro sound effects generated entirely with the browser's native Web Audio API (no external MP3 downloads required!).
6. **Collectibles & Power-ups**:
   - 🪙 **Gold Coins**: Earn +50 bonus points for every coin collected.
   - 🛡️ **Shield Orbs**: Gain 6 seconds of temporary invincibility to smash through obstacles safely.
7. **Dynamic Difficulty Ramp**: The longer you survive, the faster asteroids move and the more hazards spawn.
8. **High Score System**: Saves your best score automatically using browser `localStorage`.
9. **Responsive & Mobile Friendly**: Respects mobile safe areas (`env(safe-area-inset)`), blocks page scroll, and supports touch screens & virtual D-Pad.
10. **Accessibility**: Supports `prefers-reduced-motion` and keyboard navigation (`tabindex` and `kbd` hints).
